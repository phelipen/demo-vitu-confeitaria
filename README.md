# Vitu Confeitaria — demonstração não oficial

Conceito de Phelipe, sem vínculo ou aprovação da empresa. Portfólio: https://phelipen.dev.

React, Next.js App Router, TypeScript e Tailwind CSS. Fontes Fredoka e Nunito Sans. `npm ci`, `npm run dev`, `npm run typecheck`, `npm run build`.

Página institucional para complementar os canais existentes. O cardápio Yooga foi preservado como link. Não há checkout, confirmação de pedido, formulário ou coleta de dados. Escolhas de sabor e formato apenas preparam uma mensagem de consulta ao WhatsApp comercial. `noindex, nofollow` e aviso de demonstração visível. Sem credenciais no frontend.
